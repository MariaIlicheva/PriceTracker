# PriceTracker REST API

Базовый адрес: `http://localhost:8080/api/v1`

Формат данных: JSON (`Content-Type: application/json`)

Формат входа: HTML-форма.

Время во всех ответах — ISO 8601 в UTC, например `2026-10-27T18:00:03Z`

Цены — числа с двумя знаками после точки, например `9990.00`

## Краткое содержание

| Метод | Путь | Кто может вызвать | Назначение |
|---|---|---|---|
| GET | `/auth/csrf` | все | получить CSRF-токен |
| POST | `/auth/register` | все | регистрация |
| POST | `/auth/login` | все | вход |
| POST | `/auth/logout` | вошедший | выход |
| GET | `/me` | вошедший | текущий пользователь |
| DELETE | `/me` | вошедший | удалить аккаунт |
| GET | `/marketplaces` | вошедший | поддерживаемые магазины |
| GET | `/products` | вошедший | список своих товаров |
| POST | `/products` | вошедший | добавить товар |
| GET | `/products/{id}` | владелец товара | карточка товара |
| PUT | `/products/{id}` | владелец товара | изменить товар |
| PATCH | `/products/{id}/status` | владелец товара | пауза / возобновление |
| DELETE | `/products/{id}` | владелец товара | удалить товар |


## Общие правила

### Вход и сессия
После успешного входа сервер выставляет cookie `JSESSIONID`. Браузер отправляет её
сам со всеми следующими запросами. Запрос без входа к закрытому адресу получает
`401` без тела.

### CSRF-защита
Каждый запрос `POST`, `PUT`, `PATCH`, `DELETE` (включая вход и регистрацию)
должен содержать заголовок `X-XSRF-TOKEN` со значением токена.

1. Вызвать `GET /auth/csrf` — сервер вернёт токен и положит его в cookie `XSRF-TOKEN`.
2. Передавать его в заголовке `X-XSRF-TOKEN`.
3. После входа токен меняется — снова вызвать `GET /auth/csrf`.

Без токена или с неверным токеном сервер отвечает `403`.

### Владелец товара
Пользователь видит и меняет только свои товары. Чужой товар для него не существует:
ответ `404`, а не `403`, чтобы по ответу нельзя было узнать, что такой `id` есть.

### Формат ошибки
Все ошибки бизнес-логики и проверки данных приходят в одном формате:
```json
{
  "message": "Проверьте введённые данные",
  "fieldErrors": {
    "email": "Неверный формат почты",
    "password": "Пароль должен содержать буквы и цифры"
  }
}
```
`message` — общий текст для показа пользователю

`fieldErrors` — ошибки по полям формы (по одной на поле), где ключ это имя поля.
  Для ссылок ключ содержит номер в списке : `links[0]`, `links[1]` и тд.
  Если ошибок по полям нет — пустой объект `{}`


### Общие коды ответов
| Код | Когда |
|---|---|
| 400 | не прошла проверка данных, тело запроса не JSON, `id` не число |
| 401 | не выполнен вход |
| 403 | нет или неверный CSRF-токен |
| 404 | товар не найден или принадлежит другому пользователю |
| 409 | конфликт: почта занята, название товара занято, одновременное изменение данных |


## Авторизация

### GET /auth/csrf
Получить CSRF-токен. Доступно всем.

Ответ `200`:
```json
{ "headerName": "X-XSRF-TOKEN", "token": "3f8c1d2e-6a4b-4f0e-9b7d-2c5a8e1f0d93" }
```

### POST /auth/register
Регистрация. Доступно всем. После регистрации вход не выполняется — нужно вызвать `/auth/login`.

Тело запроса:
```json
{ "email": "masha@gmail.com", "password": "example123" }
```

`email` обязателен, формат почты, до 255 символов; без учёта регистра должен быть уникальным

`password` обязателен, от 8 до 72 символов, буквы и цифры 

Ответ `201`:
```json
{ "id": 1, "email": "masha@gmail.com" }
```

Ошибки:
| Код | Тело |
|---|---|
| 400 | `{"message": "Проверьте введённые данные", "fieldErrors": {"password": "Пароль должен быть от 8 до 72 символов"}}` |
| 409 | `{"message": "Этот адрес уже зарегистрирован. Войдите или используйте другой", "fieldErrors": {"email": "Адрес уже зарегистрирован"}}` |

### POST /auth/login
Вход. Доступно всем. Тело — HTML-форма (`Content-Type: application/x-www-form-urlencoded`):
```
email=masha%40gmail.com&password=example123
```

Ответ `200` (и cookie `JSESSIONID`):
```json
{ "id": 1, "email": "masha@gmail.com" }
```

Ошибки:
| Код | Тело |
|---|---|
| 401 | `{"message": "Неверная почта или пароль", "fieldErrors": {}}` |


### POST /auth/logout
Выход: сессия завершается. Тела нет.

Ответ `204` без тела.

### GET /me
Текущий пользователь. Фронтенд вызывает при загрузке страницы, чтобы понять, выполнен ли вход.

Ответ `200`:
```json
{ "id": 1, "email": "masha@gmail.com" }
```
Ошибки: `401` — вход не выполнен.

### DELETE /me
Удалить аккаунт вместе со всеми товарами и уведомлениями (каскадно) и завершить сессию.

Ответ `204` без тела.


## Магазины

### GET /marketplaces
Поддерживаемые магазины и их домены — для подсказки в форме добавления товара.

Ответ `200`:
```json
[
  { "code": "wb",    "name": "Wildberries",   "domains": ["wildberries.ru"] },
  { "code": "ozon",  "name": "Ozon",          "domains": ["ozon.ru"] },
  { "code": "ym",    "name": "Яндекс Маркет", "domains": ["market.yandex.ru"] },
  { "code": "kuper", "name": "Купер",         "domains": ["kuper.ru"] },
  { "code": "ali",   "name": "AliExpress",    "domains": ["aliexpress.com", "aliexpress.ru"] }
]
```
Ссылка подходит, если её домен совпадает с доменом из списка или является его
поддоменом.


## Товары

### Поля товара
| Поле | Значения |
|---|---|
| `status` | `active` — отслеживается, `paused` — на паузе (выбирает пользователь) |
| `state` | `below` — лучшая цена ниже порога, `tracking` — отслеживается, `paused` — на паузе |
| `bestPrice` | минимальная последняя цена среди ссылок или `null` до первого сбора |
| `lastPrice`, `lastCheckedAt` у ссылки | последняя собранная цена и время сбора или `null` до первого сбора |


### Обработка ссылок
Перед сохранением каждая ссылка приводится к единому виду:
- схема всегда `https://`;
- домен в нижнем регистре и без `www.`;
- убираются якорь `#...` и рекламные параметры `utm_*`.


### GET /products
Список своих товаров. Сначала товары с ценой ниже порога, внутри групп — новые сверху.
Фильтры на главном экране применяет фронтенд по полю `state`.

Ответ `200`:
```json
[
  {
    "id": 7,
    "name": "Наушники",
    "targetPrice": 9990.00,
    "status": "active",
    "state": "below",
    "bestPrice": 8990.00,
    "bestMarketplace": "Ozon",
    "linkCount": 2,
    "createdAt": "2026-10-27T20:15:42.123456Z"
  },
  {
    "id": 5,
    "name": "Чайник",
    "targetPrice": 2500.00,
    "status": "paused",
    "state": "paused",
    "bestPrice": null,
    "bestMarketplace": null,
    "linkCount": 1,
    "createdAt": "2026-10-26T09:01:10.000000Z"
  }
]
```

### POST /products
Добавить товар.

Тело запроса:
```json
{
  "name": "Наушники",
  "targetPrice": 9990,
  "links": [
    "https://www.ozon.ru/product/naushniki-123/?utm_source=vk",
    "wildberries.ru/catalog/162954398/detail.aspx"
  ]
}
```

`name` обязателен, до 255 символов, уникально среди товаров пользователя 

`targetPrice` обязателен, больше 0, до 10 цифр до точки и 2 после 

`links` - от 1 до 10 ссылок на поддерживаемые магазины, без повторов

Ответ `201` — карточка товара (формат как у `GET /products/{id}`).

Ошибки:
| Код | Тело |
|---|---|
| 400 | `{"message": "Проверьте введённые данные", "fieldErrors": {"targetPrice": "Цена должна быть больше нуля", "links": "У товара должно быть от 1 до 10 ссылок"}}` |
| 400 | `{"message": "Проверьте ссылки", "fieldErrors": {"links[0]": "Этот магазин не поддерживается. Подходят Wildberries, Ozon, Яндекс Маркет, Купер и AliExpress"}}` |
| 400 | `{"message": "Проверьте ссылки", "fieldErrors": {"links[1]": "Эта ссылка уже есть в списке"}}` |
| 409 | `{"message": "У вас уже есть товар с таким названием", "fieldErrors": {"name": "Название уже используется"}}` |

Другие тексты ошибок ссылок: «Ссылка не заполнена», «Это не похоже на ссылку»,
«Ссылка должна вести на сайт и начинаться с https://», «В ссылке нет адреса сайта»,
«Ссылка слишком длинная» (больше 2048 символов).

### GET /products/{id}
Карточка товара со всеми ссылками. Ссылки — в порядке добавления.

Ответ `200`:
```json
{
  "id": 7,
  "name": "Наушники",
  "targetPrice": 9990.00,
  "status": "active",
  "state": "below",
  "bestPrice": 8990.00,
  "createdAt": "2026-10-27T20:15:42.123456Z",
  "links": [
    {
      "id": 12,
      "marketplaceCode": "ozon",
      "marketplaceName": "Ozon",
      "url": "https://ozon.ru/product/naushniki-123/",
      "lastPrice": 8990.00,
      "lastCheckedAt": "2026-10-27T18:00:03Z"
    },
    {
      "id": 13,
      "marketplaceCode": "wb",
      "marketplaceName": "Wildberries",
      "url": "https://wildberries.ru/catalog/162954398/detail.aspx",
      "lastPrice": null,
      "lastCheckedAt": null
    }
  ]
}
```
Ошибки: `404` — `{"message": "Товар не найден", "fieldErrors": {}}`.

### PUT /products/{id}
Изменить название, порог и набор ссылок. Тело, правила и ошибки (и 404) — как у `POST /products`.
Передаётся **полный** список ссылок после изменения:
- ссылки, которых нет в новом списке, отвязываются от товара;
- новые ссылки добавляются;
- оставшиеся не меняются — их история цен сохраняется.

Ответ `200` — обновлённая карточка товара.


### PATCH /products/{id}/status
Поставить товар на паузу или возобновить. На паузе уведомления не приходят,
но цена продолжает собираться, если ссылку отслеживает кто-то ещё.

Тело запроса:
```json
{ "status": "paused" }
```

Ответ `200` — обновлённая карточка товара.

Ошибки:
| Код | Тело |
|---|---|
| 400 | `{"message": "Проверьте введённые данные", "fieldErrors": {"status": "Статус может быть active или paused"}}` |
| 404 | `{"message": "Товар не найден", "fieldErrors": {}}` |

### DELETE /products/{id}
Удалить товар вместе с его уведомлениями. Если на ссылку больше не подписан
ни один товар, она удаляется вместе с историей цен .

Ответ `204` без тела.

Ошибки: `404`.
